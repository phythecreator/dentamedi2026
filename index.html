Auto-Avaliação Ortodôntica

Teste para Alinhadores Invisíveis

Responda a 4 perguntas rápidas para perceber se o seu caso é elegível para este tratamento.

1. Tem a disciplina para usar os alinhadores durante 22 horas por dia, retirando-os apenas para comer e escovar os dentes?

Nota do formulário: Se responder Não, o tratamento vai falhar por falta de uso.

2. Como está a sua saúde oral atual?

Nota do formulário: Se tiver problemas, terá de tratá-los no dentista antes de poder usar os alinhadores.

3. Tem implantes dentários ou coroas/pontes fixas?

Nota do formulário: Os implantes não se movem. O dentista precisará de avaliar se eles impedem o movimento dos restantes dentes.
